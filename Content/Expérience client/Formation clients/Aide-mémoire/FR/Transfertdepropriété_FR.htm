PROCÉDURE DE RÉALISATION

N°

Desc.

Comment faire

Vérification

1

Ouvrir le courriel Starlink

Dans votre boîte de réception, ouvrez le courriel de Starlink intitulé « Ready to Activate ». Cliquez sur le bouton « Activate Starlink ».

Si vous ne trouvez pas ce courriel, passez à l’étape 2.

Le site Starlink s’ouvre directement sur la page d’activation. Vous pouvez sauter à l’étape 4.

2

Ouvrir le site Starlink

Sur un ordinateur ou smartphone, ouvrez starlink.com.

La page d’accueil Starlink s’affiche.

3

Choisir l’activation du matériel existant

Cliquez sur « Activate Existing Hardware » (Activer un matériel existant).

Un formulaire de création de compte apparaît.

4

Sélectionner votre pays

Choisissez 🇨🇦 Canada ou 🇺🇸 United States selon votre adresse de service.

Le pays choisi détermine le service et les forfaits proposés.

5

Renseigner vos coordonnées

Saisissez : nom, e-mail, téléphone, adresse postale.

Votre compte personnel est créé. Vous recevez un e-mail de confirmation.

6

Saisir le numéro de kit

Entrez le numéro de kit de votre antenne.

L’antenne déjà installée est rattachée à votre compte.

7

Choisir votre forfait

Sélectionnez le forfait Starlink adapté à votre usage (mobile, domicile, etc.).

Le tarif mensuel s’affiche.

8

Confirmer le paiement

Saisissez votre moyen de paiement et confirmez l’activation.

Le service démarre. La facturation est désormais à votre nom.

Si une étape bloque, identifiez le symptôme dans le tableau ci-dessous.

Les 4 pièges fréquents à éviter

1.  Cliquer sur « Order Now » au lieu de « Activate Existing Hardware ». Vous achèteriez une seconde antenne. Votre matériel est déjà installé : choisissez toujours « Activate Existing Hardware ».

2.  Sélectionner le mauvais pays. Le service ne fonctionnera pas dans votre région. Vérifiez avant de valider.

3.  Utiliser l’e-mail d’un proche ou du concessionnaire. Le compte doit être au nom du propriétaire — vous-même. Sans cela, vous ne pourrez pas modifier le forfait ni contacter le support en votre nom.

4.  Reporter l’activation à plus tard. Tant que le système n’est pas activé à votre nom, le service ne fonctionnera pas, même si l’antenne est installée.

 

Quand appeler le support — et qui

Vous appelez Loki Coach si :  le numéro de kit est introuvable, le matériel ne semble pas reconnu, ou vous avez un doute avant de valider.

Vous appelez Starlink si :  vous avez activé le service mais rencontrez un problème de connexion, de facturation ou de forfait.
